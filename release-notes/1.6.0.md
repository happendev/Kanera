You can now bring work into Kanera from a CSV file, whichever tool or spreadsheet it came from. Automations gain four new triggers, and a connected AI agent can set up workspaces and boards for you.

## Import cards from a CSV file

Open **Workspace settings** or **Board settings**, choose **Import**, then **CSV**. Kanera detects the file's encoding and delimiter and suggests what each column means. Map one column to **Title** and choose what the others become: description, list, due date, labels, assignees, comments, checklist items or custom fields.

Map an issue key to **Card ID / group** to combine several rows into one card, which suits exports such as Jira's. You then create or match lists, labels, custom fields and people, and review everything before any card is created. A file can be up to 20 MB, with up to 20,000 rows and 200 columns.

## Start automations from more events

Four new triggers are available under **When** in an automation. **Card leaves a list** runs when a card moves out of a list, even to another board. **Due date is approaching** runs a chosen number of days before a card is due.

**Card becomes inactive** runs once a card passes the workspace's inactivity period, and **Custom field changes to a value** runs when a field reaches the value you pick. The event, list and action pickers in the automation editor now show an icon and a description for each option.

## Let an AI agent set things up

When your organisation has no boards yet, Home offers to set one up with you or to connect an AI agent. Copy the setup prompt into Claude, Copilot, Codex, ChatGPT or another compatible agent. Kanera opens a browser sign-in, so you do not need an API key. On Kanera Cloud, connecting an AI agent is part of Kanera Pro.

Organisation admins' agents can now create workspaces and standalone boards from Kanera's templates and add boards to a workspace. Onboarding also has **Skip for now** if you would rather start later.

## New features

- [Import] Import cards from CSV with column mapping, row grouping and a review step
- [Automations] Card leaves a list, Due date is approaching and Card becomes inactive triggers
- [Automations] Custom field changes to a value trigger
- [Onboarding] Connect an AI agent from Home or onboarding to set up your boards
- [MCP] Create workspaces and standalone boards from templates, and add boards to workspaces
- [SDK] Create workspaces, standalone boards and workspace boards from the SDK

## Improvements

- [Automations] Event, list and action pickers show icons and descriptions
- [Onboarding] **Skip for now** lets you leave onboarding and set up later from Home
- [Guests] Home lists board invitations that are waiting for you
- [MCP] Tools are renamed, for example `kanera_get_card` is now `cards.get`; update tool allowlists

## Bug fixes

- [Guests] Board invitation links are no longer lost when you sign up or sign in first
- [Table] Labels in Table view are no longer squashed in narrow columns
- [Cards] Renaming a checklist item with a long title from its detail panel works again

## Self-hosting

- Valkey is now pinned to `valkey/valkey:9.1.2-alpine`; after pulling, run `docker compose up -d valkey` to recreate it.
