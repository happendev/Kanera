A day after launch, this release gives AI agents connected through MCP the same checklist controls you have in the app, and fixes loading and live-update problems in card detail.

## New features

- [MCP] Agents can create, edit, reorder and delete checklists and checklist items
- [MCP] Agents can duplicate cards, move them to another board and mark them complete
- [MCP] Agents can list card comments, workspace members and Work done history
- [Editor] Type `---` in a description to insert a horizontal rule

## Improvements

- [Members] Name and profile picture changes appear for everyone straight away

## Bug fixes

- [Cards] Card detail shows clear loading states instead of stale or half-loaded content
- [Comments] Reactions that arrive while comments are still loading are no longer lost
- [Cards] Card activity stays visible while your session refreshes in the background
- [Notifications] Opening a card marks its notifications read only once
- [Comments] Mentions with a profile picture line up with the surrounding text
