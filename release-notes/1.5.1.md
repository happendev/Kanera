Kanera now includes a plugin for Codex that bundles the Kanera connection and the Kanera skill, so Codex knows how to work with your cards from the start.

AI agents connected to Kanera now use Kanera's MCP tools for anything those tools support, instead of automating the web app. When you give an agent an exact card key such as `DEV-938` or a card link, it reads that card directly rather than searching for it.

When MCP tools are not available, the Kanera skill tells agents that can run shell commands to use the `kanera` CLI instead.

## New features

- [AI agents] A Kanera plugin for Codex with the Kanera connection and skill bundled

## Improvements

- [MCP] Agents use Kanera tools instead of browser automation for supported work
- [MCP] Agents read a card directly when you give them its key or link
- [AI agents] The Kanera skill falls back to the CLI when MCP tools are unavailable
- [CLI] Try the CLI without installing it by running `npx -y @kanera/cli commands`
