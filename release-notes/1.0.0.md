Kanera 1.0 is the first public release. You organise work in workspaces, boards, lists and cards, and every board in a workspace shares the same lists, labels and custom fields, so related boards stay consistent without being set up one by one.

Use Kanera on Kanera Cloud, where new organisations start with a 30-day Pro trial, or run it on your own infrastructure with Docker Compose. The self-hosted edition uses the same code as Kanera Pro and has no per-seat charge.

## Boards, cards and views

Each board opens in **Board** view, with **List**, **Calendar** and **Work done** views a click away. List view groups and sorts cards, lets you choose columns, totals numeric custom fields with **Sum** or **Avg**, and exports to Excel or JSON.

Cards hold a description, comments with mentions and reactions, attachments, labels, custom fields, watchers, due dates and checklists whose items can be assigned and dated. Select several cards to move, label, assign, date, complete, copy or archive them together.

**My Cards** and **Team Cards** in each workspace bring together the cards and checklist items assigned to you or a teammate across that workspace's boards.

## Automations

Automations run on every board in a workspace. Each one waits for an event, such as a card entering a list, a due date arriving, all checklist items being completed or a label being set, then applies its actions in order.

Actions can add or remove labels and assignees, apply checklist templates, set or clear the due date, mark a card complete, move it to a list or to the top or bottom, and fill in a custom field.

## New features

- [Boards] Workspaces share lists, labels and custom fields across all their boards
- [Boards] Board view, List view, Calendar view and Work done view on every board
- [Boards] Private boards, board groups, backgrounds and titled separators between cards
- [Cards] Text, number, date, checkbox, select and person custom fields
- [Cards] Checklist templates and assignable checklist items with due dates
- [Comments] Mentions, emoji reactions and attachments in comments
- [Notes] Workspace and board notes with a page tree
- [My Cards] My Cards and Team Cards show assigned work across a workspace
- [Notifications] In-app, email and push notifications, plus a daily email digest
- [Guests] Invite people from outside your organisation to selected boards
- [Import] Import from Trello or a Kanera export; export boards to Excel or JSON
- [API] REST API with workspace API keys, plus signed webhooks
- [MCP] MCP server so AI agents can read and update boards, cards and notes
- [Mobile] Installable app with an offline copy and sharing into a new card
- [Self-hosting] Docker Compose and Dokploy deployment guides
