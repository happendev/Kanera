Board health is now **Board overview**. Select the radar button beside the board name to see how many cards are active, overdue, unassigned and inactive, how many are due in the next 7 days, and how cards are spread across your lists.

The overview no longer scores the board with a risk level, and there is no setting to switch it on: it is available on every board. Select a count to filter the board to those cards, or jump straight to Work done or Portfolio.

## Add a separator between any two cards

Separators now go in the same place new cards do. Hover the gap between two cards and choose **Add separator** beside **Add card** to label a group of cards exactly where it starts, instead of adding the separator elsewhere and dragging it into place.

## Let agents react to changes with MCP events

MCP 4.0.0 adds MCP events. An agent that supports them, such as ChatGPT, can subscribe to new cards, card changes, card moves and new comments in a workspace, board, list or single card, and to changes in your own Up next queue. Kanera sends each event to the agent's signed webhook, so it can act without checking back.

Checklists also take fewer calls. An agent can create a checklist with all its items and sub-checklists at once, or update many items in one request.

## Sign in to the CLI with your browser

CLI 2.0.0 adds `kanera auth login`. It prints a link and a short code and opens your browser, where you approve the sign-in; it works over SSH too. Add `--agent "Claude Code"` when an AI agent drives the CLI, so its work is labelled with that agent's name.

At most once a day the CLI checks for a newer version and offers to update after your command finishes. It never asks in scripts, CI or agent sessions, and `KANERA_NO_UPDATE_CHECK=1` turns the check off.

## New features

- [Boards] Board overview replaces Board health, with card counts and cards by list
- [Boards] Add a separator between any two cards from the gap between them
- [Notes] Admins can turn Notes off for a workspace or standalone board without deleting notes
- [Mobile] Install Kanera as an app from **Install Kanera** in your account menu
- [Import] An email summarises what each Trello, CSV or Kanera import brought across
- [Onboarding] On Kanera Cloud, organisation admins get setup tip emails they can turn off
- [MCP] Subscribe to card, comment and Up next changes with MCP events
- [MCP] Create or update a whole checklist, including sub-checklists, in one call
- [CLI] `kanera auth login` signs you in through your browser
- [CLI] The CLI offers to update itself when a new version is available
