Remind yourself about any card. Select the alarm button in card detail, or right-click a card on the board and choose **Remind me…**, then pick a quick option or any date and time up to eight weeks ahead.

Reminders are private: nobody else sees them, and they change nothing on the card. When one comes due you get a single notification, by email, push or a personal channel too if you choose. Cards with a reminder show a small alarm, Home lists your upcoming reminders, and the board's **Filter** has a **Reminder set** option. Completing a card clears its reminders.

## See and clear what uses your storage

Organisation owners and admins have a new **Storage** page under **Settings**, in the **Organisation** tab. It shows how much space card attachments, shared notes and personal notes use, and which workspaces use the most.

**Clean up files** lists the largest and oldest files, including files on archived cards that are out of sight but still take up space. Select up to 100 at a time and delete them. On Kanera Cloud, owners and admins also get an email when the organisation reaches 80% of its allowance.

## Hand work to AI agents

Start a workspace from the new **Agent Workflow** template when agents do most of a board's work. Its **Backlog**, **Agent Working**, **Waiting on Me**, **Review** and **Done** lists follow an agent's run, so the board shows at a glance what agents are doing and what is waiting for you.

On Kanera Cloud, the Free plan now includes AI agents: Claude, ChatGPT, Cursor, the CLI and personal API keys all work on Free-plan boards. Agents can now set reminders, capture "remind me to…" notes to your scratchpad, read and upload attachments, create up to 50 cards in one call, and pick up your replies and @mentions without a webhook. Cards an agent creates for you are watched automatically.

## New features

- [Cards] Set a private reminder on any card, up to eight weeks ahead
- [Organisations] A Storage page shows usage and lets admins delete up to 100 files at once
- [Members] Select a person's avatar to see their profile card and recent activity
- [Organisations] Organisation admins can turn Portfolio off for everyone
- [Security] On Kanera Cloud, admins set AI agent access to Off, Read only or Read and write
- [Onboarding] An Agent Workflow template whose lists follow an agent's runs
- [Settings] Copy MCP setup snippets for Claude Code, Cursor, VS Code, Codex and Gemini CLI
- [AI agents] Agents get a "my day" summary of overdue, due and stale cards plus Up next
- [AI agents] Agents can set reminders, capture scratchpad tasks, and read and upload attachments
- [MCP] Create up to 50 cards in one call, and poll your inbox without a webhook
- [CLI] New `kanera my-day`, `kanera capture`, `kanera inbox` and `kanera remind` commands

## Improvements

- [Billing] On Kanera Cloud, the Free plan includes AI agents, the CLI, MCP and personal API keys
- [API] Rate limits apply per person, per second and per minute, with a short queue for bursts
- [AI agents] You automatically watch cards your agent creates for you
- [MCP] A smaller tool list, and read-only connections see only read tools
- [Settings] Settings are split into **Your account** and **Organisation** tabs
- [Notes] Every workspace member can edit the workspace's team notes
- [Performance] Fewer database queries, re-renders and round trips across the app

## Bug fixes

- [Editor] The editor no longer freezes, and notes save reliably
- [My Cards] My Cards and Team Cards refresh correctly again
- [Security] Organisation invitations can no longer skip mandatory two-factor authentication
- [Cards] Checkbox custom fields show correctly on cards
- [MCP] Expired or revoked agent credentials prompt the agent to reconnect

## Self-hosting

- Releases publish amd64 and arm64 images to `ghcr.io/happendev`, so you no longer build Kanera yourself.
- Download `docker-compose.yml` and `env.example` from the GitHub release; the compose file pins that version.
- Images are tagged `1.9.0`, `1.9` and `1`; there is no `latest` tag.
- Choose local disk or S3-compatible upload storage on the Storage settings page.
- Tune per-person API limits with `PUBLIC_API_KEY_RATE_LIMIT_PER_SECOND` (default 20) and `PUBLIC_API_RATE_LIMIT_QUEUE_SIZE`.
