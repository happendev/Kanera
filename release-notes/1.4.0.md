The scratchpad is a private place to write things that are not ready for a card, comment or note: meeting prep, personal to-dos, rough drafts and pasted screenshots. Only you can open it, and each organisation has its own set of pages.

Open it with the **Scratchpad** button at the top right, or press **Ctrl+Shift+.** (**Command+Shift+.** on a Mac). On desktop it docks as a column you can resize, and the page beside it stays usable. On a narrow screen it opens as a bottom sheet.

A scratchpad holds up to 50 pages. Use **New page** to add one and the page list to switch, rename, reorder or delete them. Paste screenshots or drop files straight into a page. Changes save as you type, and **Not saved** appears only when a change could not be stored. Open the scratchpad in its own browser tab when you want more room.

## Preview Markdown attachments

Markdown files attached to cards and notes now open in the attachment viewer as formatted text, alongside images, video, audio and PDFs. Select a `.md` file to read it without downloading it first.

## Retry API writes safely

The public API now accepts an `Idempotency-Key` header on writes. If a request fails part-way and you send it again with the same key within 24 hours, Kanera returns the original result instead of making the change twice. Keys belong to the credential that used them.

Workspace automations can now be managed through the API and MCP: list them, create and update them, switch them on or off, delete them, and read their run history. These actions need workspace admin access.

## New features

- [Scratchpad] A private scratchpad with up to 50 pages, docked beside any page
- [Cards] Preview Markdown attachments as formatted text on cards and notes
- [API] Send an `Idempotency-Key` header to make retried writes safe for 24 hours
- [API] Manage workspace automations and read their run history through the API
- [MCP] Workspace admins can list, create, update, switch on or off and delete automations

## Improvements

- [Up next] **Up next** now sits beside **Filter** in My Cards and Team Cards, with a count
- [Up next] On Team Cards, select one teammate to open their Up next queue
- [Cards] Removing an attachment within two minutes of adding it clears both from activity
- [API] The API reference documents the error responses each endpoint can return

## Bug fixes

- [Cards] Pasting a file into the new card composer adds it as an attachment
- [Editor] Links that use a card's key-based URL show as card links, like other card links
- [Editor] Blank lines in descriptions are kept after pasting and reloading
- [My Cards] A card opened from My Cards stays open when another card on its board changes
