On Kanera Cloud, you can sign up, sign in or accept an invite with your Google, Microsoft or GitHub account instead of a password. An account the provider has verified links to your existing Kanera account with the same email; otherwise Kanera emails you a code first. Connect or disconnect accounts, or add a password, under **Account → Security**.

Signing in this way satisfies an organisation's two-factor requirement. If you turned on two-factor authentication yourself, you're still asked for the code.

## Invite people straight onto boards

An organisation invite can now grant specific boards as **Editor** or **Observer**, so the person lands on those boards when they join, and an invite no longer needs a workspace. Owners and admins can create one from a board's members menu. Add an email address when you create an invite in **Users** and Kanera sends the link to it.

## New features

- [Security] On Kanera Cloud, sign in with Google, Microsoft or GitHub
- [Members] Invites can grant specific boards as Editor or Observer
- [Members] Kanera emails an invite link to the address you add
- [Onboarding] Boards from a template start with a few example cards
- [Security] Emails when your password, two-factor settings or email address change

## Improvements

- [Members] A redesigned board members menu: search, add existing guests by name, invite guests by email, and see pending invites
- [Onboarding] Signing up asks only for your name, email and password
- [Notifications] Emails name the card or person, and card emails have an Open card button
- [Mobile] Setup keeps its Create board and Continue buttons in view on phones

## Bug fixes

- [Security] Signing out clears offline copies, drafts, recent history and pending shares

- [Security] Malformed input returns validation errors, and exports can't inject formulas
