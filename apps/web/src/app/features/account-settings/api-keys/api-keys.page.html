Personal API keys

A personal key acts as you: it is evaluated against everything you can access, and activity done with it shows up as you. A write key can create and edit anything you can, including workspace administration where you are an admin. A read key can read everywhere but cannot change content, manage keys, or touch account settings — the right one to hand an AI agent. A key's scope can't be changed after creation; revoke it and create a new one instead.
